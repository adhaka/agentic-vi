Skip any unaffordable entire operation, retain partial endpoints, permit their labeled diagnostics. Unused allocations never transfer. A backend capability declaration prevents unsupported HVP reservations from being spent.
- NumPy PCG64 with SeedSequence([1, root, integer stream tag, horizon tag]); tags follow init, train, gradient, importance, curvature, bootstrap in that order. Use zero horizon tag for init and training to pair prefixes. Diagnostic tags include requested horizon. Matched arms and dimensions reuse seed IDs intentionally. Bootstrap draws only resample already charged products.
- Use NumPy Adam ascent algebra with defaults from Section 4. Use the last floor(T_completed/2) post-update states. The minimum of 40 means observations in that window before splitting. Coordinate summaries with undefined/infinite coordinates are unavailable as full-vector summaries. Signed drift splits discard an odd central observation.
